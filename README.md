UNIVOICE – Every Voice Matters 

An Android-Based Assistive Communication Application

About the Project

UNIVOICE is an Android application designed to support accessible communication by recognizing selected hand gestures and converting them into meaningful text. The application also provides text-to-speech, translation, sentence building, and gesture recognition history features.

The goal of UNIVOICE is to make everyday communication more accessible and convenient.

Features

- **Gesture Recognition:** Recognizes selected hand gestures using the device camera.
- **Text-to-Speech:** Converts text into spoken audio.
- **Language Translation:** Supports translation between English, Hindi, and Marathi.
- **Sentence Builder:** Allows users to combine words or phrases into sentences.
- **Recognition History:** Saves recognized gestures for later reference.
- **User Profile:** Provides a profile screen.
- **User-Friendly Interface:** Built with a simple Android interface and helpful visual elements.

Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3
- CameraX
- MediaPipe Gesture Recognizer
- Google ML Kit Translation

Getting Started

### Prerequisites

- Android Studio
- Android SDK
- A compatible Android device or emulator
- Internet access for downloading project dependencies

Installation

1. Clone this repository:

   git clone https://github.com/asthajaiswal1006-a11y/UNIVOICE.git

2. Open the downloaded project in Android Studio.
3. Allow Gradle to sync and download the required dependencies.
4. Connect an Android device or start an emulator.
5. Build and run the application.
